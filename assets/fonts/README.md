# 字体放这里

程序启动时会加载本目录下所有 `*.ttf`（私有加载，不写入系统字体目录）。

推荐的字体（仓库不附带，需自行下载）：

- **MiSans** — <https://hyperos.mi.com/font/zh/download/>
  下载后取 `MiSans-Regular.ttf`、`MiSans-Medium.ttf`、`MiSans-Bold.ttf`
- **JetBrains Mono** — <https://www.jetbrains.com/lp/mono/>
  取 `JetBrainsMono-Regular.ttf`、`JetBrainsMono-Bold.ttf`

放好后重启程序，字体下拉框里就会出现它们。一个都不放也能正常用，会回退到系统的微软雅黑。
